# 頂樓尋物 (`pg-atticfind`)

> 一九九九年夏末，颱風登陸前的最後半天。
> 阿嬤走了三個月，她交代過：「紅色那個鐵盒，裡面那封信，要幫我寄出去。」
> 她沒說盒子在哪，也沒說要寄給誰。

**隱藏物件＋故事章節**：四個場景、四段章節、一個推理結局。純 HTML／CSS／JavaScript，無 build。

## 怎麼玩

- **點光點＝搜查。** 場景裡會呼吸的光點就是可以點的地方，搜到的東西自動進背包。紅色光點代表那裡需要條件或道具。
- **拿道具＝使用。** 先點背包裡的道具把它拿起來，再點光點就是「用在這裡」；用錯會自動放回背包。
- **連點兩件＝組合。** 手電筒配電池、紅鐵盒配小銅鑰匙。
- **章節自己會走。** 每一章的目標寫在畫面最上方；條件湊齊就自動推進，並打開下一個場景。
- **風雨計是輸贏。** 推進章節、用錯東西會讓它往上跳；壓住翹起的鐵皮、清掉排水口會把它壓回去，壓不掉的存成「加固」，之後風雨要漲會先扣加固。**滿八格＝鐵皮被掀走，這一夜什麼都寄不出去。**
- **卡住就按「卡住了」。** 提示會跟著章節指出方向，不會直接講答案。

## 通關條件

四章走完、打開紅鐵盒讀到信之後進入尾聲。這時要從線索本裡的東西推出這封信該寄給誰，
在四個候選人裡挑一個寫上信封——**寫對就寄出去，通關**；寫錯不會馬上輸，但雨會一次灌進來三格，
除非你一路把加固存夠，錯兩次就守不住了。線索不齊時按名字只會被自己攔下來，不算失誤。

四個場景：頂樓加蓋 → 曬衣平台 → 樓梯間儲藏室 → 前廳。

## 開發

```bash
npx vitest run
```

`game.js` 是純函式（無 DOM），所有規則都可以單測；`app.js` 只負責畫面與聲音。
`content.js` 放場景／熱點／道具／章節資料，`art.js` 是程式繪製的向量場景。

進度一律存在宿主的 `/api/kv`（見 `persist.js`），不把 localStorage 當權威。
頁內不使用 `alert`／`confirm`／`prompt`，破壞性操作（重來）用頁內確認條。
